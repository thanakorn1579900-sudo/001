# เชื่อมผลสอบเข้ากับ Google Sheets

1. เปิด Google Sheets ที่กำหนดไว้ แล้วเลือก **ส่วนขยาย > Apps Script**
2. วางเนื้อหาจาก `Code.gs` แทนโค้ดเดิม แล้วบันทึก
3. เลือก **ทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้** แล้วสร้างเวอร์ชันใหม่ของเว็บแอป
4. ตั้งค่าให้เว็บแอปทำงานในบัญชีเจ้าของชีต และอนุญาตให้เข้าถึงได้โดยผู้ที่มีลิงก์
5. คัดลอก URL ที่ลงท้ายด้วย `/exec` ส่งให้ผู้ดูแลเว็บไซต์เพื่อตั้งค่า `GOOGLE_APPS_SCRIPT_URL`

เมื่อมีนักเรียนส่งข้อสอบ เว็บไซต์จะสร้างชีตตามชื่อ **ครูผู้ออกข้อสอบ** ให้อัตโนมัติ เช่น `ครูธนากร สมปาน` และบันทึกชื่อ ชั้น/ห้อง รหัสนักศึกษา รายวิชา คะแนน เวลา และจำนวนครั้งที่ออกจากหน้าสอบไว้เฉพาะชีตของครูท่านนั้น

หากครูเปลี่ยนชื่อ ระบบจะใช้ชื่อใหม่เป็นชีตปลายทางสำหรับผลสอบครั้งถัดไป เพื่อให้ชื่อชีตตรงกับรายชื่อครูในระบบสอบ
