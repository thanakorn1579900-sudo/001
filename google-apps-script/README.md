# เชื่อมผลสอบเข้ากับ Google Sheets

1. เปิด Google Sheets ที่กำหนดไว้ แล้วเลือก **ส่วนขยาย > Apps Script**
2. วางเนื้อหาจาก `Code.gs` แทนโค้ดเดิม แล้วบันทึก
3. เลือก **ทำให้ใช้งานได้ > การทำให้ใช้งานได้ใหม่** และเลือกชนิดเป็น **เว็บแอป**
4. ตั้งค่าให้เว็บแอปทำงานในบัญชีเจ้าของชีต และอนุญาตให้เข้าถึงได้โดยผู้ที่มีลิงก์
5. คัดลอก URL ที่ลงท้ายด้วย `/exec` ส่งให้ผู้ดูแลเว็บไซต์เพื่อตั้งค่า `GOOGLE_APPS_SCRIPT_URL`

เมื่อเชื่อมแล้ว เว็บไซต์จะสร้างชีตชื่อ **ผลสอบ** ให้อัตโนมัติ และบันทึกชื่อ ชั้น/ห้อง รหัสนักศึกษา คะแนน เวลา และจำนวนครั้งที่ออกจากหน้าสอบ
